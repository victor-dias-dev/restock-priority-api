# Security Policy

## Supported versions

Security fixes are applied to the latest 1.x release of this repository.

## Reporting a vulnerability

Email [vitorlirio@hotmail.com](mailto:vitorlirio@hotmail.com) with the subject line `restock-priority security`.

Include the affected version, a description of the impact, and a way to reproduce the issue. Do not open a public GitHub issue for a vulnerability.

You can expect an acknowledgement within 3 business days. Fixes and a public note ship after the report is confirmed.
